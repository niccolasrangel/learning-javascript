# 02 — DOM e navegador

## Tópicos

- Seleção e atualização de elementos do DOM
- Eventos de formulário e interação
- Atributos e classes CSS
- Persistência de dados com `localStorage`

## Projeto

O projeto `projetos/todo-list/` permite adicionar tarefas, marcá-las como concluídas e removê-las. As tarefas ficam salvas no navegador.
