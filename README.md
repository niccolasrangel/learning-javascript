# Estudos de JavaScript

Repositório para organizar estudos, exercícios e pequenos projetos de JavaScript.

## Trilha de estudos

1. **Fundamentos** — variáveis, tipos, operadores, condicionais, laços e funções.
2. **DOM e navegador** — manipulação do DOM, eventos e armazenamento local.
3. **Async e APIs** — Promises, `async`/`await` e consumo de APIs.
4. **Ferramentas** — Git, npm, módulos e ferramentas de desenvolvimento.
5. **React** — componentes, estado, propriedades e hooks.
6. **Backend** — Node.js, APIs e persistência de dados.
7. **Qualidade e portfólio** — testes, acessibilidade e projetos publicados.

## Como executar

Os exercícios de JavaScript podem ser executados com Node.js:

```bash
node 01-fundamentos/exercicios/01-variaveis.js
node 01-fundamentos/exercicios/02-funcoes.js
```

Para testar a lista de tarefas, abra `02-dom-navegador/projetos/todo-list/index.html` no navegador.
